# GRAVITY LAB - NEXTブロック待機 × 物理演算パズルゲーム

## 概要

**GRAVITY LAB** は、Matter.jsの2D物理演算エンジンをフル活用した「物理パズルゲーム」です。  
テトリスのようにステージ外の「NEXT待機エリア」に表示されたブロックをクリックしてステージ内に投入し、マウスで移動・回転させてボールをゴールへと導きます。

ゲーム開始時にステージ内に大量のブロックが存在して暴れ回る問題を解消し、プレイヤーが意図したタイミングで必要なブロックを1つずつ投入して攻略する戦略的なパズルゲームとなっています。

## 画面構成 (3カラムレイアウト)

```text
┌────────────────────────────────────────────────────────┐
│                      GRAVITY LAB                       │
├─────────────┬───────────────────────────┬──────────────┤
│ NEXT BLOCKS │        GAME STAGE         │  GAME INFO   │
│             │         (Canvas)          │              │
│  [#1 NEXT]  │                           │  TIME        │
│   🪶 LIGHT  │     ⚪ (Ball)             │  00:15.3     │
│   [ 投入 ]  │    ＼                     │              │
│             │                           │  STAGE       │
│  [#2 NEXT]  │         📦                │  1 / 5       │
│   ⚡ BOUNCE │           ＼              │              │
│   [ 投入 ]  │                           │  SCORE       │
│             │              🏁 (Goal)    │  12,500      │
│  [#3 NEXT]  │                           │              │
│   ⚓ HEAVY   │                           │  MOVES       │
│   [ 投入 ]  │                           │  4           │
├─────────────┴───────────────────────────┴──────────────┤
│         RELEASE BALL  /  RETRY  /  RESET               │
└────────────────────────────────────────────────────────┘
```

* **左カラム（NEXT BLOCKS）**:
  * 物理空間から完全に分離された待機エリア。
  * 次に使用できるブロックが1〜3個表示されます。
  * クリックまたはドラッグでステージへ投入。投入されて初めて物理演算（重力・衝突・反発）が適用されます。
* **中央カラム（GAME STAGE）**:
  * メイン物理演算フィールド。
  * ステージ開始時は物理ブロックが**0個**で、開始直後に暴れ回ることは一切ありません。
* **右カラム（GAME INFO）**:
  * タイマー、ステージ、スコア、操作手数、ゲーム状態をリアルタイム表示。

## 主な仕様 & ゲームシステム

### 1. ゲーム状態とタイマーの連動
* **TITLE（起動直後）**:
  * タイマーは `00:00.0` で完全停止。
  * ボールは初期位置で静止（物理演算待機）。
  * ステージ内の物理ブロックは0個。
* **PLAYING（START後）**:
  * 「START GAME」をクリックした瞬間にタイマーが `00:00.0` から計測開始。
  * ブロックを投入・操作可能になり、ボールを発射してテストできます。
* **CLEAR / GAME_OVER**:
  * ゴール到達またはボール落下時にタイマーがピタリと停止。
  * リトライ時はタイマーが `00:00.0` にリセットされ、再開時から再計測されます。

### 2. 4種類のブロックと物理特性
ブロックごとに物理特性と外観（カラー・アイコン・枠線・ラベル）が異なります。

| ブロック種類 | 見た目・アイコン | 密度 (Density) | 反発係数 (Restitution) | 摩擦係数 (Friction) | 特徴・用途 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **通常ブロック (NORMAL)** | 📦 アンバーオレンジ | 0.002 (標準) | 0.30 (標準) | 0.35 (標準) | 標準的な質量・摩擦・反発。安定した橋や滑り台に最適。 |
| **軽いブロック (LIGHT)** | 🪶 スカイブルー | 0.0003 (極小) | 0.45 (中反発) | 0.12 (滑りやすい) | 質量が小さく、ボールに衝突されると簡単に弾き飛ばされる。 |
| **重いブロック (HEAVY)** | ⚓ スレートメタル | 0.030 (超高密度) | 0.05 (ほぼ無反発) | 0.85 (高摩擦) | 超大質量でボールが当たってもビクともしない。強固な土台や重石に。 |
| **バウンドブロック (BOUNCE)** | ⚡ ネオンピンク | 0.003 (標準) | 1.45 (超高反発) | 0.02 (低摩擦) | ボールを強く弾き飛ばす。高所への大ジャンプ台や加速器に。 |

### 3. ブロックの「固定状態 (FIXED)」と「操作中 (HELD)」メカニクス
本ゲームでは、プレイヤーが意図したタイミングと形状でボールと干渉させられるよう、ブロックの状態を明確に2つに分離しています。

* **固定状態（FIXED）**:
  * ステージに配置・離したブロックはすべてこの状態になります。
  * **当たり判定OFF（すり抜け）**: `isSensor = true`, `collisionFilter.category = FIXED`, `mask = 0`。
  * **物理演算OFF**: `isStatic = true`。重力の影響を受けず、その場に留まり落下しません。
  * **ボールとの関係**: ボールは固定中のブロックをそのまま通過（すり抜け）します。
  * **視覚表現**: 半透明表示、破線枠、「📌 FIXED」アイコン表示。
* **操作中（HELD）**:
  * プレイヤーがブロックをクリックまたはドラッグして**持った瞬間**に切り替わります。
  * **当たり判定ON（衝突有効）**: `isSensor = false`, `collisionFilter.category = HELD`, `mask = BALL | WALL | HELD`。
  * **物理演算ON**: `isStatic = false`。ボールや他の物体と物理衝突して跳ね返します。
  * **視覚表現**: 高輝度ネオングロー、実線枠、「✋ MOVING (HIT ON)」バッジ、回転角度表示。
* **離した瞬間（RELEASE）**:
  * ブロックを離すと即座にその位置・角度で「固定状態 (FIXED)」に戻り、再び当たり判定がOFFになります。
  * これにより、「ブロックを配置する」→「ボールを転がす」→「狙ったタイミングでブロックを持ってボールを反射・誘導する」といったリアルタイムなアクションパズルが可能になります。

### 4. プレイヤー操作
* **NEXT投入**: 待機カードをクリックしてステージ上空へ投入（投入時は即座にFIXED状態で固定）。
* **ドラッグ移動**: マウスまたはタッチでブロックを掴んで自由に移動（掴んだ瞬間当たり判定ON）。
* **ブロック回転操作**:
  * **マウスホイール**: 掴んでいるブロックをクルクルと精密に角度調整可能。
  * **キーボード操作**: `R` / `E` キーで時計回り、`Q` キーで反時計回りに回転。
* **ブロック状態UI**: 右側のGAME INFOパネル内の「BLOCK STATE」カードで、現在掴んでいるブロックの状態（FIXED / MOVING）をリアルタイムに確認可能。

### 5. ボール操作 & 試行錯誤
* **RELEASE BALL**: ゲートを開放し、ボールを物理世界へ解き放ちます。
* **RETRY**: ボールが奈落に落ちた場合、**配置したブロックはそのまま維持**してボールのみ初期位置に再装填。微調整しながら何度もテストできます。
* **RESET**: ステージ上のブロックを消去して0個に戻し、タイマーをリセットして最初からやり直します。
