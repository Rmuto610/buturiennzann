# GRAVITY LAB - Matter.js 2D物理演算パズルゲーム

## 概要

**GRAVITY LAB** は、Matter.jsの2D物理演算エンジンをフル活用した「物理演算アクションパズルゲーム」です。  
プレイヤーが直接ボールを操作するのではなく、ステージ上の物体をマウスで動かしてボールのルートを切り開き、ゴールへと導きます。

READMEに規定されたすべての物理演算機能（重力・衝突・反発・摩擦・質量・相互作用・パラメータリアルタイム変更）を維持し、パズルゲームの攻略要素として組み込んでいます。

---

## ゲームコンセプト & ルール

* **プレイヤー操作**: マウスドラッグで「緑色の枠線」が付いた物体（木箱、クサビ、高反発バンパー、超重量鉄球など）を掴んで移動・配置・投げることができます。
* **直接操作の禁止**: 主役のボールを直接掴んでゴールへ運ぶことはできません。物体を動かしてボールの軌道や道を作ります。
* **重力 & 物理演算**: ボールや動的オブジェクトには重力が働き、壁・ブロック・傾斜スロープとリアルタイムに衝突・反発・摩擦します。
* **ボール解放 (RELEASE BALL)**: 物体を配置した後、「RELEASE BALL」を押すとボールが解き放たれ、重力に従って転がり始めます（走行中もリアルタイムに物体を動かしてアシスト可能）。
* **ゴール (STAGE CLEAR)**: ボールが光るネオンポータル（GOAL）に入るとステージクリアとなり、スコアが算出されます。
* **落下失敗 (GAME OVER)**: ボールが谷や画面外に落ちるとゲームオーバーとなり、「RETRY」で即座にやり直せます。
* **スコア評価**: クリアタイム、物体を動かした手数（MOVES）、リトライ回数に応じてスコアが計算され、★3つ星評価（★★★）が表示されます。

## 5つのステージと物理演算ギミック

各ステージは、Matter.jsの異なる物理特性を攻略の鍵として設計されています。

### Stage 1: Slope & Gap（基本ステージ）
* **テーマ**: 基本の重力・衝突・転がり。
* **ギミック**: スロープの途中に大きな穴（隙間）があり、そのままではボールが画面外へ落下してしまいます。
* **攻略法**: 動かせる木箱ブロック（Box）をドラッグして穴にセットし、橋を架けてゴールへ導きます。

### Stage 2: Block Bridge（動かせるブロックの積み木）
* **テーマ**: ブロックの積み重ね、摩擦、滑り落ち。
* **ギミック**: ボールが落ちる先に深い谷と段差があります。
* **攻略法**: サイズの異なる複数のブロックをドラッグして谷に積み上げ、ボールが渡れるブリッジや階段スロープを構築します。

### Stage 3: Super Bouncer（高反発オブジェクト）
* **テーマ**: 反発係数（Restitution 1.55 の超高反発トランポリン）。
* **ギミック**: ゴールが右上の高い浮島（通常では届かない高所）にあります。
* **攻略法**: 落ちてくるボールの軌道上に高反発バンパーや角度付きクサビを配置し、ボールを勢いよく跳ね上げて高所ゴールにホールインワンさせます。

### Stage 4: Heavy Seesaw（超重量オブジェクトとシーソー仕掛け）
* **テーマ**: 質量比（Density / Mass）とテコの原理（回転ピン Constraint）。
* **ギミック**: 中央にシーソーがあり、右端にボールが待機。右上の空中にゴールがあります。
* **攻略法**: 超重量の「Heavy Ball（通常の40倍の質量を持つ鉄球）」を持ち上げてシーソーの左端に落とすと、超質量の衝突エネルギーでシーソーが激しく跳ね上がり、ボールがカタパルトのように高空ゴールへ打ち上がります。

### Stage 5: Chain Master（複数物体の連鎖と順序）
* **テーマ**: 複数物体の相互作用、質量・反発・順序の組み合わせ。
* **ギミック**: ドミノタワー、倒れる跳ね橋、重い鉄球、高反発バンパー、クサビが組み合わさった最難関ステージ。
* **攻略法**: 「どの物体をどの順番で動かすか」を考え、クサビで鉄球を誘導してドミノタワーを倒し、その先に高反発バンパーをセットしてボールをゴールへ導きます。

## 維持されている物理演算機能（README完全準拠）

1. **重力 (Gravity)**:
   - すべての物体に重力が働き、落下・転がりが発生。
   - 画面下の「PHYSICS TWEAKS」パネルから、0.0G（無重力）〜 2.5G（超重力）までリアルタイムに変更可能。
2. **衝突 (Collision)**:
   - 円形、四角形、ポリゴン（三角形）のボディが重なり合わずに正確に反発・押し合い。
3. **反発 (Restitution)**:
   - スライダーで全体の反発係数をリアルタイム調整可能。高反発バンパー（よく跳ねる）と鉄球（ほとんど跳ねない）の違い。
4. **摩擦 (Friction)**:
   - スライダーで全体の摩擦係数を変更可能（氷のようなツルツルから高摩擦まで）。
5. **質量 (Mass & Density)**:
   - 通常ボール、木箱、超重量鉄球（Heavy Ball）の質量比によるインパクトの違い。
6. **インタラクション (MouseConstraint)**:
   - マウスでドラッグして持ち上げ、勢いをつけて投げる物理操作。
7. **リセット (RESET / RETRY)**:
   - ステージの初期配置リセット、およびボールの再装填リトライ。
8. **音響 & 視覚エフェクト**:
   - Web Audio API による衝突音（強度・質量に応じたシンセサイズ音）、バウンス音、ファンファーレ音。
   - 衝突時の衝撃波リング・パーティクル、およびクリア時の紙吹雪エフェクト。
9. **情報表示**:
   - FPS、OBJECTS（動的物体数）、GRAVITY、STAGE、SCORE、TIMER、MOVES。
